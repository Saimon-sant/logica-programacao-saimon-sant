Algoritmo:
-É uma série de passos para solucionar um problema
Entrada:
-São os dados que o algoritmo recebe para solucionar os problemas
Processamento:
-É fase em que o algoritmo processa os dados fornecidos
Saída:
-Resultado obtido após o processamentos dos dados
Exemplo do dia a dia:
-Dirigir carro
1. destravar as portas
2. abrir a porta
3. entrar no carro
4. sentar no banco
5. ajustar banco
6. ajustar retrovisores
7. colocar o cinto
8. engatar a chave
9. dá partida
10. passar marcha
11. sair com o carro
